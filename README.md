## English

A collection of DeepSeek Harness plugins. Each plugin now lives in its own repository:

| Plugin | Description | Repository |
| --- | --- | --- |
| dsh-yunxiao | Lightweight Yunxiao (Alibaba Cloud DevOps) workbench for accounts, projects, defects and pipelines — no database required | [aliyun-workbench](https://github.com/zhangcheng-zzz/aliyun-workbench) |
| dsh-port | Windows port management: workbench and model tools to look up processes holding ports and kill them | [win-port-manage](https://github.com/zhangcheng-zzz/win-port-manage) |

See each repository's README for installation, configuration, token permissions and development verification.
